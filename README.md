# KodiPlay Kodi repozitar

Verejny Kodi repozitar pre auto-update doplnku **plugin.video.kodiplay**.
Generuje sa z hlavneho (sukromneho) projektu cez `kodi-addon/deploy_repo.py`.

Instalacia v Kodi: Nastavenia -> Doplnky -> Instalovat zo suboru ZIP ->
`repository.kodiplay/repository.kodiplay-1.0.0.zip`, potom Instalovat z repozitara.
